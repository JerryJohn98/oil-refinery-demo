# Calculation Cycle Frontend

## Overview

This is the frontend component of the Calculation Cycle Plugin for the iLens 2.0 platform. Built with Angular, it provides a user interface for configuring and visualizing calculation cycles, process orders, and dashboard data.

## Features

- Angular-based single-page application
- Responsive UI with Bootstrap
- Date/time filtering components
- Dropdown filters for hierarchies and cycles
- Integration with backend APIs

## Setup

1. Install dependencies: `npm install`
2. Configure environment files
3. Run development server: `ng serve`
4. Build for production: `ng build`

## Development

- `ng serve`: Start development server
- `ng build`: Build the project
- `ng test`: Run unit tests
- `ng generate component <name>`: Generate new components

## Structure

- `src/app/`: Main application code
- `src/assets/`: Static assets
- `src/environments/`: Environment configurations

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
